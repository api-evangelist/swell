# Swell GraphQL API

Client-side API and Swell.js SDK for building custom storefronts. Exposes products, categories, accounts, sessions, addresses, credit cards, carts, orders, payments, coupons, promotions, gift cards, subscriptions, store settings, currencies, localization, navigation menus, and payment options. Includes a GraphQL frontend option for headless storefronts.

**Endpoint:** https://api.swell.store

**Documentation:** https://developers.swell.is/frontend-api/introduction
